# Welcome to Aisphere

Welcome to the Aisphere documentation website! Aisphere is an AI-native service infrastructure platform built around a specification-driven microservice framework.

## What is Aisphere?

Aisphere consists of several key components:

- **Kernel** — The specification-driven microservice foundation framework
- **IAM** — Identity and access management service
- **Hub** — AIHub business service for skill management
- **Gateway** — Edge gateway for routing and access control
